# 语法库接续标记规范

本规范适用于 `shared/grammar-db-core.js` 中所有语法卡的 `connection` 字段。

## 权威依据

- 国立国语研究所「日本语文型 Bank」的[接续标记说明](https://www2.ninjal.ac.jp/bunkeibank/about.html)与「日本语文型数据库（2026.01）」。
- 国际交流基金日语教材中采用的活用形名称（如[「Vない形」](https://www.kyozai.jpf.go.jp/kyozai/material/BTS00065/ja/render.do)）。
- 数据库未收录的高级、固定或口语表达，参照《教師と学習者のための日本語文型辞典》等工具书，并以本库当前卡片所讲的用法和例句为审查范围。

## 统一名称

| 类别 | 统一写法 | 不再使用 |
| --- | --- | --- |
| 动词基本形 | 动词辞书形 | 动词原形 |
| 动词词干 | 动词ます形去掉「ます」 | 第一连用形、连用形 |
| 否定形 | 动词ない形 | 动词否定形（泛称） |
| 过去形 | 动词た形 | — |
| 连接形 | 动词て形 | — |
| 假定形 | 动词ば形 | 动词假定形(ば) |
| 意向形 | 动词意向形 | 动词意志形 |
| 普通形 | 普通形／动词普通形等 | 普通体 |
| 形容词 | イ形容词／ナ形容词 | い形、な形 |
| 名词 | 名词 | 名詞 |

「普通形」沿用国立国语研究所的定义，包含动词、イ形容词、ナ形容词和名词的肯定／否定、非过去／过去形式。某个文型要求ナ形容词或名词省略「だ」、改用「な／の／である」时，必须在接续中单独写明。

## 符号

- `＋`：前后成分依次连接。
- `／`：可以替换使用的完整接法或形式。
- `・`：同一位置可用的并列活用形。
- `（ ）`：其中内容可以省略。
- `※`：不规则变化、使用限制或必须注意的例外。
- 数字 `1／2`：表示前后不同的词或成分；“同一动词”则明确写出，不用数字代替。

接续字段只说明构成方式，不写释义、使用场景或完整句法说明；这些内容分别放入卡片的“含义”和“解说”。
