# 柴柴学习小屋

一个独立、无需账号的桌面浏览器小游戏。操控柴犬，在书桌记录真实学习，用爪印币购买家具，再亲手布置小屋。

## 打开游戏

直接用电脑 Chrome 或 Safari 打开本目录的 `index.html`。全部图像与声音由本地代码生成，不需要下载素材。

也可以从这个目录启动本地预览：

```sh
python3 -m http.server 8873 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8873/`。要预览主页与小屋之间的往返，请从项目根目录启动服务，再访问 `/shiba-study-cottage/index.html`。固定使用同一入口：直接打开文件和本地预览地址属于不同的浏览器存储空间。

## 怎么玩

- **出门：**点击左上角入口返回主页；已提交的学习与已确认的布置会保留。
- **WASD／方向键：**移动柴犬。
- **鼠标点地板：**自动走到目标位置，遇到家具会绕路。
- **鼠标点家具：**走到互动位置后自动使用。点柴犬会出现摸摸回应，不产生经济奖励。
- **Shift + 移动键：**快走。手动移动、Esc 或右键可以取消自动路线。
- **E：**靠近物品后互动。左上角书桌记录学习，左下角信箱买家具。
- **B：**进入／退出布置。点击家具拿起，再点击格子放下。
- **Esc：**关闭面板、取消当前摆放，或结束休息。
- **收纳箱：**拿出已拥有的家具。所有家具都可以免费移动和收纳。
- **摆放时方向键／Enter：**逐格微调并放下；鼠标拿起家具会保持拿起的位置，避免跳动。
- **Z／撤销：**撤销这次布置中的上一步，最多保留 20 步。只恢复家具位置，不撤销购买，也不改动余额；退出布置后结束这组撤销记录。
- **学习手账：**查看完整学习记录、累计分钟数和今日奖励。
- **设置：**修改柴犬名字，独立开关生活音效与背景音乐。

## 小屋操作

页面沿用 ki 主页的灰米背景、白色纸面、细暖灰边框、圆角与枫红操作色。顶部只显示今日学习和余额，房间旁保留柴柴名字、当前动作与常用照顾操作；学习明细在手账查看，操作说明在设置中展开。

- **摸摸／喝水／休息／看云：**直接照顾柴柴。喝水、休息和看云会实际走到对应家具；没有摆放水碗或小窝／沙发时，对应按钮不可用。轻点移动键即可起身接手。
- **记录学习：**走到书桌并打开学习记录。书桌被收纳时会提示先摆出来。
- **布置侧栏：**按全部、已摆放、收纳中筛选已拥有的家具，选中后在房间预览，再点击或 Enter 放下；取消、收纳和撤销沿用原有规则。
- **商店与收纳箱：**按买得起、已拥有或摆放状态筛选，显示占地尺寸、价格和还差多少币。
- **手账：**按全部、今天、近 7 天或学习内容查找记录，按北京时间分组，并统计当前筛选的总时长。
- **拍照按钮：**下载一张 1152 × 864 的 PNG 小屋照片，保持清晰的 3 倍像素。布置完成后可拍照。

大窗口使用“小屋＋陪伴操作”两栏；较窄窗口将陪伴操作移到房间和工具栏下方，较矮窗口会缩小为整数倍并让工具换行。基础画布仍为 384 × 288。页面新增功能无需迁移存档。

## 柴柴的自在活动

默认开启。连续约 8 秒没有操作且柴柴处于待机状态时，它会自己慢慢散步、停下张望、去窗边看云、喝水，或回小窝／沙发打盹，也会伸懒腰、打哈欠、挠耳朵和低头闻闻。第一次会先走一小段；之后按权重挑选可到达的活动，活动之间休息 4～8 秒，各种小动作都有冷却间隔，避免连续重复。

按键、点击地板或家具、摸摸柴柴都能立即接手；打开面板、输入内容、进入布置或切走窗口时停止自主活动。返回后重新等待，不补做离开期间的动作。玩家主动选择的休息、学习庆祝和行走路线会被尊重。

设置中的「自在活动」可以关闭，选择会随存档保存。已有 version 1 存档没有这个选项时默认开启。活动本身不写存档、不记录学习、不发币或购物，也不会主动开启音乐；地板路线与家具互动位置沿用现有碰撞和绕路逻辑。家具布局改变后会取消旧活动，重新选择。

每条学习记录可填 5～180 分钟；1 分钟对应 1 爪印币，每个北京时间自然日最多获得 120 币。达到上限后仍记录全部学习时长。学习由玩家手动确认，提交后只读。

学习面板提供 15／25／45／60 分钟快捷选择，支持 Ctrl／⌘ + Enter 提交。关闭面板后可继续填写未提交的内容；草稿只保留在当前打开的页面中，刷新或关闭网页后不会恢复，也不会产生学习奖励。手账里的「记录学习」会让柴犬实际走到书桌；商店里已拥有的物品可以直接选取摆放。

存档仅位于当前浏览器，使用独立键 `shibaStudyCottage.v1`，不读取或改写 ki计划的数据。清理网站数据会清除进度；换浏览器不会自动同步。存储失败时不会扣款或发奖，页面会保留明确的重试提示。损坏的存档不会被自动覆盖。

## 实现结构

- `data.js`：家具配置、地图边界与奖励上限。
- `model.js`：学习结算、购买、布局可达性、存档验证与保存。
- `art.js`：32 色像素场景、家具、离屏缓存和角色动画图集。
- `sprite-metadata.json`：由实际图集导出的帧坐标、时长、朝向和调色板。
- `audio.js`：本地合成生活音效与原创背景旋律。
- `autonomy.js`：待机计时、活动选择、间隔、休息与手动接管。
- `game.js`：键盘移动、脚部碰撞、互动、布置预览与绘制顺序。
- `ui.js`、`style.css`：弹窗、手账、设置、状态反馈与整数倍缩放。

Canvas 基础尺寸为 384 × 288，格子为 16 × 16，角色帧为 32 × 32。角色动画图集在启动时生成，帧间有透明留白；不依赖网络图片或外部字体。

美术采用统一的左上方受光：木板有错缝、木纹与节疤，窗边包含亚麻帘褶、远树、栅栏和小路；家具补充藤编、陶瓷反光、刺绣与布料缝线。柴犬的耳尖、卷尾、奶白脸颊和动作均按原生像素重绘。窗光和落地灯通过调色板提亮保留地板纹理，灯光位于地毯下层。背景、家具和灯光使用离屏缓存。

柴犬采用圆脸、短耳、圆眼和小短腿的幼犬比例，毛色更偏奶油橘；四个朝向与读书、趴卧、喝水、庆祝、摸摸动作保持统一形象。摸摸时会眯眼并露出小舌头。角色仍为 32 × 32 像素，脚部原点和碰撞尺寸保持一致。

角色现在包含 **22 组、94 帧**动画：四朝向待机各 4 帧、行走各 4 帧、小跑各 4 帧，六组已有互动各 4 帧，以及伸懒腰／哈欠／挠耳各 6 帧、闻闻 4 帧。待机加入呼吸和耳朵微动，睡觉时偶尔动动爪子与卷尾，喝水时伸出小舌头；Shift 快走会使用独立的小跑步态。新增小动作只播放一次，再自然回到待机，按键可立即打断。

场景补充墙面织纹、地板细木纹、地毯编织、墙脚阴影、窗台小花与屋外苔草石子。窗帘、窗外树叶和地板斑驳树影使用四组缓存姿态；水碗有小波纹，马克杯有热气，唱片实际播放时有转动细节。开启系统「减少动态效果」会停止这些环境装饰变化。

## 验证

不需要安装游戏依赖即可运行逻辑测试：

```sh
node --test tests/model.test.cjs tests/autonomy.test.cjs
```

浏览器验收脚本使用已有的 Playwright 与本机 Chrome，在隔离的测试浏览器中执行。不会修改现有浏览器资料：

```sh
PLAYWRIGHT_MODULE=/path/to/playwright node tests/browser-smoke.cjs
PLAYWRIGHT_MODULE=/path/to/playwright node tests/interaction-polish.cjs
PLAYWRIGHT_MODULE=/path/to/playwright node tests/art-check.cjs
PLAYWRIGHT_MODULE=/path/to/playwright node tests/autonomy-browser.cjs
PLAYWRIGHT_MODULE=/path/to/playwright node tests/room-ui.cjs
```

可用 `COTTAGE_URL` 指定预览地址，用 `COTTAGE_ARTIFACTS` 指定截图和测试报告目录。

美术检查会生成完整家具展示、94 帧动画预览、小动作展示和房间截图，并验证调色板、透明边缘、动画留白、单次播放和环境动态。展示家具使用隔离测试存档，不会改变玩家进度。

首版只支持电脑键盘和鼠标；手机操控、多房间和与现有学习网站联动不在此版本中。
